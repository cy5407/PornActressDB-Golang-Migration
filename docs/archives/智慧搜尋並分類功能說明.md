### 2. 新增智慧搜尋並分類方法 ✅
**檔案**: `src/services/classifier_core.py`

**新增方法**: `smart_search_and_move()`

**方法簽名**:
```python
def smart_search_and_move(
    self, 
    folder_path: str, 
    stop_event: threading.Event, 
    progress_callback=None, 
    use_full_search=False
)
```

**參數說明**:
- `folder_path`: 要處理的資料夾路徑
- `stop_event`: 停止事件（支援中途取消）
- `progress_callback`: 進度回調函式（用於顯示進度）
- `use_full_search`: 是否使用完整搜尋
  - `True`: AV-WIKI → chiba-f → JAVDB
  - `False`: AV-WIKI → chiba-f（預設，推薦）

**執行流程**:
1. **掃描影片檔案**
   - 掃描目標資料夾中的影片檔案
   - 顯示找到的檔案數量

2. **檢查並搜尋無資料番號**
   - 識別需要搜尋的番號：
     * 資料庫中沒有此番號
     * 有番號但女優列表為空
     * 搜尋狀態為 `search_error` 或 `no_actress_found`
   - 根據 `use_full_search` 參數選擇搜尋方法
   - 批次搜尋並儲存結果到資料庫

3. **執行智慧分類**
   - 呼叫原有的 `move_files()` 方法
   - 單人作品：自動分類
   - 多人共演：啟動互動選擇

**特色**:
- ✅ 支援中途取消（透過 `stop_event`）
- ✅ 自動跳過已有資料的番號
- ✅ 完整的進度回報
- ✅ 異常處理與錯誤記錄

### 3. 新增 GUI 按鈕 ✅

**新增方法**:

- `_smart_search_and_move_worker()`: 背景執行緒工作者

**使用者體驗**:

## 🎯 使用情境

### 情境 1: 新下載的影片批次處理
1. 選擇包含新影片的資料夾
2. 點擊 **🔍📁 智慧搜尋並分類**
3. 選擇搜尋方式（建議選「否」，只用日文網站）
4. 確認執行
5. 系統自動完成搜尋與分類

### 情境 2: 處理之前搜尋失敗的檔案
根據 `show_research_needed.py` 分析，目前有：
- 18 個 `search_error` 狀態的番號
- 8 個 `empty_actresses` 狀態的番號

處理方式：
1. 將這些影片檔案移到同一個資料夾
2. 使用 **🔍📁 智慧搜尋並分類** 重新處理
3. 如果日文網站找不到，可選擇完整搜尋（含 JAVDB）

### 情境 3: 混合狀態的資料夾
資料夾中有：
- 部分已搜尋有資料的影片
- 部分未搜尋的新影片

處理方式：
1. 直接使用 **🔍📁 智慧搜尋並分類**
2. 系統會自動跳過已有資料的番號
3. 只搜尋需要的番號
4. 全部一起分類
