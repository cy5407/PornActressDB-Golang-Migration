## 問題診斷

用戶報告 50+ 個番號出現「未找到女優資訊」的警告，示例包括：
- FSDSS-180, SNIS-515, STARS-814, SONE-709, EBWH-118 等

### 根本原因
排除關鍵詞過多，導致許多有效的女優名稱被誤判為垃圾文本。

---

## 修復方案

### 簡化排除規則
**檔案**: `src/scrapers/sources/avwiki_scraper.py` - `_is_valid_actress_name()` 方法

**改進前**: 46 個排除關鍵詞（過度嚴格）
```python
exclude_keywords = [
    'SOD', 'STARS', 'FANZA', 'MGS', ...  # 太多片商代碼
    'シロウト', 'プレステージ', ...      # 太多系列名
    'コスプレ', '美少女', '人妻', ...    # 太多分類
    'です', 'ます', 'ました', ...       # 否定詞
    # ... 以及許多其他詞彙
]
```

**改進後**: 12 個排除關鍵詞（精簡關鍵）
```python
exclude_keywords = [
    'ありません',       # 沒有（核心否定詞）
    'ありませんでした', # 沒有了
    'いない',          # 不存在
    'ない',            # 否定
    'ません',          # 否定
    'です',            # 判定詞（不應單獨出現）
    'ます', 'ました',  # 敬體
    'Menu', 'star', 'SOKMIL',  # 系統詞
    'actress',         # 英文標籤
]
```

### 關鍵改進
✅ 移除了過多的片商代碼和分類詞（這些不應在文本掃描時被排除）  
✅ 只保留核心的否定詞和系統詞  
✅ 保持 2-8 字長度限制和日文字符要求  
✅ 保持數字檢查邏輯
