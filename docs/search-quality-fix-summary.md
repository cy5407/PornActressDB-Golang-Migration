# 搜尋品質問題修正總結

## 📋 問題描述

番號 `SAVR-00410` 的女優欄位包含 **717 個**錯誤項目，全部都是：
- 片商名稱（如：`シロウト逸材発掘`）
- 網站/系列名稱（如：`ラポルノリコピンルナティックス`）
- 標籤/分類（如：`系パコパコ`、`炉利`）

## 🔍 根本原因

1. **過於寬鬆的正則表達式**
   - `[\u3040-\u309F\u30A0-\u30FF\u4E00-\u9FAF]{2,20}` 抓取所有 2-20 字元的日文字串
   - 沒有充分的語意過濾

2. **排除清單不完整**
   - 原本只有 13 個排除關鍵詞
   - 缺少片商、系列、網站名稱等常見詞彙

3. **無數量限制**
   - 沒有檢查女優數量是否合理
   - 超過 10 位女優通常代表解析錯誤

## ✅ 已實作修正

### 1. 擴充排除清單（13 → 60+ 個關鍵詞）

新增以下分類：
- **片商/系列名稱** (20+)：`シロウト`、`エスワン`、`プレステージ`、`ハメ撮り`、`パコパコ`、`ナンパ` 等
- **網站/平台** (10+)：`ギャラリー`、`チャンネル`、`レーベル`、`プロジェクト` 等
- **分類/標籤** (15+)：`素人`、`人妻`、`巨乳`、`コスプレ`、`企画`、`配信` 等
- **動作/描述詞** (10+)：`逸材`、`発掘`、`系`、`専科`、`倶楽部`、`ちゃん`、`さん` 等
- **常見組合詞** (5+)：`ラビリンス`、`ルナティックス`、`リコピン`、`ヤリマン` 等

### 2. 長度限制（20 → 8 字元）

```python
# 女優名稱通常不超過 8 字元
if len(name) > 8:
    return False
```

### 3. 數量檢查機制

```python
# 品質檢查
if len(actresses) == 0:
    search_status = 'no_actress_found'
elif len(actresses) > 10:
    search_status = 'search_error'
    actresses = []  # 清空錯誤結果
elif len(actresses) > 3:
    search_status = 'searched_multiple'  # 需要人工確認
else:
    search_status = 'searched_found'  # 正常
```

## 🔄 再次搜尋策略

### 建議邏輯

```python
def should_research(video_info: dict) -> bool:
    """判斷是否需要再次搜尋"""
    
    status = video_info.get('search_status')
    actresses = video_info.get('actresses', [])
    
    # 情況 1: 搜尋錯誤 → 再次搜尋
    if status == 'search_error':
        return True
    
    # 情況 2: 未找到女優 → 再次搜尋
    if status == 'no_actress_found' or not actresses:
        return True
    
    # 情況 3: 女優列表為 ['XXXX'] → 需用戶確認
    if actresses == ['XXXX']:
        return ask_user("是否重新搜尋?")
    
    # 情況 4: 多位女優 (可能是合集) → 需用戶確認
    if status == 'searched_multiple':
        return ask_user(f"找到 {len(actresses)} 位女優，是否正確?")
    
    # 情況 5: 已找到正常結果 → 跳過
    return False
```
